# Saved Grit42 query records

Files in this directory are source records for
`vcgen_query.import_grit42_subject_query()`. They are not
`vcgen.subject_query.v1` documents and the VCGen service does not accept them
directly.

The importer compiles a saved record into a subject query. Endpoint selection
is a separate stage. The compiled counterpart of the hosted debug fixture is
`../queries/hosted_debug_wistar_han_28d.yaml`.
