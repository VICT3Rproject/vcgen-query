# Saved Grit42 query records

Files in this directory are source records for
`vcgen_query.import_grit42_subject_query()`. They are not
`vcgen.cohort_query.v5` documents and the VCGen service does not accept them
directly.

The importer combines a saved record with an explicit, non-empty
`requested_endpoints` list. The compiled local v5 counterpart of the hosted
debug fixture is `../queries/hosted_debug_wistar_han_28d.yaml`.
